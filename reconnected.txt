PART 1 — FIRST TIME INSTALL (run once in Termux)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Open Termux on your Android phone

Step 2: Paste this ONE command to install everything:

  curl -sL https://raw.githubusercontent.com/bantuvoice/NasTech/main/auto_setup.sh | bash

   OR if that doesn't work:

  pkg install -y git && git clone https://github.com/bantuvoice/NasTech.git ~/NasTech && bash ~/NasTech/auto_setup.sh

PART 2 — SHIZUKU SETUP (MUST DO — gives phone control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Shizuku lets the bot control your phone WITHOUT root.
You must do this ONCE. After that it reconnects automatically.

── METHOD A: Wireless Debugging (Recommended — works on Android 11+) ──────────

1. Enable Developer Options:
   → Settings → About phone
   → Tap "Build number" 7 times fast
   → You'll see "You are now a developer!"

2. Enable Wireless Debugging:
   → Settings → Developer options
   → Scroll down, find "Wireless debugging"
   → Turn it ON
   → Tap "Wireless debugging" text (not the toggle) to open it
   → You'll see a pairing code and port number

3. Open Shizuku app:
   → Tap "Start" button
   → Choose "Start via Wireless Debugging"
   → Shizuku will pair automatically
   → Top of Shizuku app should say "Shizuku is running" ✅

4. Connect Shizuku to Termux:
   → In Shizuku app, tap "Use Shizuku in terminal apps"
   → Tap "Export files"
   → A folder picker opens
   → Navigate to: Internal Storage (the root)
   → Find or create a folder named "Shizuku"
   → Tap on that "Shizuku" folder
   → Tap "USE THIS FOLDER" button at the bottom
   → Tap "Allow" on the popup

5. Go back to Termux and run:
   nastech-reconnect

6. You should see: "✅ Shizuku connected! rish is working."


── METHOD B: ADB via PC (if Method A doesn't work) ───────────────────────────

1. Install ADB on your PC: https://developer.android.com/tools/releases/platform-tools
2. Enable USB Debugging: Settings → Developer options → USB debugging → ON
3. Connect phone to PC via USB
4. On PC, open terminal/cmd:

   adb devices
   (Accept the fingerprint popup on your phone)

   adb shell sh $(pm path moe.shizuku.privileged.api | awk -F: '{print $2}')/assets/rish

5. Now in Shizuku app → tap "Use Shizuku in terminal apps" → "Export files"
   → Choose the Shizuku folder → Use This Folder → Allow
6. In Termux: nastech-reconnect


── METHOD C: If Shizuku keeps disconnecting ───────────────────────────────────

Run this in Termux every time you restart the phone:

   shizuku

   Then:

   nastech-reconnect

   To make it auto-start on boot, add to Termux's startup:

   echo 'sleep 5 && shizuku' >> ~/.bashrc


── VERIFY Shizuku is working ──────────────────────────────────────────────────

   rish -c whoami

   ✅ Should print: shell  (or u0_a...)
   ❌ If error: Shizuku is not connected, repeat steps above

PART 3 — START THE BOT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

After install, start the bot:

   nastech bot

   OR (same thing):

   cd ~/.nastech/bot && node nastech_bot.js --mode=bot

To start as background service (runs even when Termux is closed):

   nohup nastech bot > ~/.nastech/bot.log 2>&1 &

To stop it:

   pkill -f nastech_bot

PART 4 — TELEGRAM BOT SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Open Telegram → search @BotFather → /newbot
2. Follow prompts, get your BOT TOKEN (looks like: 123456:ABCdef...)
3. Get your Telegram user ID: message @userinfobot → copy the "Id:" number
4. Edit the config:

   nano ~/.nastech/config.env

   Set:
   export TELEGRAM_BOT_TOKEN="YOUR_BOT_TOKEN_HERE"
   export TELEGRAM_ADMIN_ID="YOUR_USER_ID_HERE"

5. Save (Ctrl+O then Ctrl+X in nano)
6. Start the bot: nastech bot
7. Open Telegram → find your bot → send /start
8. Keyboard buttons appear at the bottom of the chat ✅

PART 8 — FIX COMMON ERRORS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ERROR: "rish_shizuku.dex not found"
  FIX: Open Shizuku app → Use Shizuku in terminal apps → Export files
       → Pick the Shizuku folder → Allow
       Then: nastech-reconnect

ERROR: "Shizuku is not running"
  FIX: Open Shizuku app → tap Start → Start via Wireless Debugging
       Enable Wireless Debugging in Developer Options first
       Then: shizuku && nastech-reconnect

ERROR: "TELEGRAM_BOT_TOKEN not set"
  FIX: nano ~/.nastech/config.env
       Add: export TELEGRAM_BOT_TOKEN="your_token"
       Save → nastech bot

ERROR: "Cannot find module 'node-telegram-bot-api'"
  FIX: cd ~/.nastech/bot && npm install

ERROR: "Ollama offline" or AI not working
  FIX: nastech serve   (starts Ollama)
       ollama pull tinyllama   (download a model)
       OR the bot falls back to Groq/Gemini automatically

ERROR: "yt-dlp not found"
  FIX: pip install yt-dlp
       OR: pip3 install yt-dlp

ERROR: Files not found on phone
  FIX: Run in Termux: termux-setup-storage
       Tap Allow on popup
       Then try again

ERROR: Bot polling conflict (another instance running)
  FIX: pkill -f nastech_bot
       nastech bot
